# Previous Work

This replication package is associated with the study:

```text
Property-Based Testing of ML-Based Anomaly Detectors under Incomplete Ground Truth
```

The empirical study builds on two previous contributions by the authors. These
works provide scientific provenance for the anomaly taxonomy and predicate-based
formalization used to instantiate the PBT campaign, but they are not required to
run the public replication package.

## IFAC 2026

```text
M. A. Carrero-Hernandez, M. Munoz, M. Torres, A. Becerra-Teron,
and F. Rodriguez.
Ensuring Data Reliability in Smart Greenhouse: A Machine Learning Framework
for Taxonomy-Driven Anomaly Detection.
23rd IFAC World Congress, 2026. In press.
```

This work provides the empirical anomaly-analysis background for the greenhouse
sensor setting. In particular, it documents the taxonomy-driven anomaly
detection perspective from which the anomaly behaviours considered in the PBT
campaign were derived.

## QRS 2026

```text
M. A. Carrero-Hernandez, M. Munoz, M. Torres, A. Becerra-Teron,
and F. Rodriguez.
From Anomaly Detection to Formal Correction: A Predicate-Based Reliability
Layer for IoT Climatic Sensor Data.
26th International Conference on Software Quality, Reliability and Security,
2026. In press.
```

This work provides predicate-oriented methodological provenance for representing
sensor anomalies as executable conditions in IoT climatic data. The present
replication package uses a revised PBT-oriented instantiation focused on
behavioural evaluation of a frozen ML-based anomaly detection and
classification SUT.

## Scope of This Repository

The camera-ready manuscripts of the previous works are not included in this
repository. The repository is intentionally limited to the public replication
package for the PBT campaign: executable code, frozen SUT artifacts, aggregate
campaign evidence, post-hoc analysis outputs, and figure-generation scripts.

When official DOI or publisher links become available for the previous works,
they can be added here as bibliographic pointers.
